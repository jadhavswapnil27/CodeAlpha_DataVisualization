# CodeAlpha - Social Media Analytics Dashboard

## Project Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship – Task 3: Data Visualization**.

The project presents an interactive **Social Media Analytics Dashboard** created using Microsoft Power BI. The dashboard visualizes social media performance using likes, comments, shares, engagement, platforms, posts, and time-based trends.

## Objectives

- Analyze social media performance
- Compare engagement across different platforms
- Track likes over time
- Analyze likes, comments, and shares
- Identify high-performing posts
- Create an interactive and informative dashboard

## Tool Used

- Microsoft Power BI
- Data Visualization
- Power BI Filters and Slicers

## Dashboard Features

### KPI Cards
- Total Likes
- Total Comments
- Total Shares
- Average Engagement

### Visualizations
- Likes Trend by Date
- Shares by Platform
- Likes vs Comments by Post
- Likes by Platform
- Top Posts by Likes

### Filters
- Platform
- Date / Time-based filtering

## Key Insights

- The dashboard compares engagement across **Facebook, YouTube, and Instagram**.
- Likes, comments, and shares provide an overview of social media interaction.
- The time-series chart shows how likes change over time.
- Platform-wise analysis helps compare overall engagement.
- Post-level analysis helps identify posts with higher numbers of likes.

## Technologies Used

- Microsoft Power BI
- Power Query
- Data Visualization
